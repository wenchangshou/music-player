# 听音室 · Android 播放器

听音室是以本地音乐为默认入口的 Android 播放器。首页提供续播和最近播放，音乐库按歌曲、专辑和本地歌单整理文件，搜索可在本地与 TIDAL 之间切换。TIDAL 登录和多端后台按需启用。

## 本地音乐

在 **音乐库 → 导入** 选择音频文件，或选择 **扫描文件夹** 授权目录。应用递归扫描子目录，读取歌名、艺人、专辑、专辑艺人、流派、年份、碟号、曲号和内嵌封面。音乐文件保存在原位置。

在音乐库点 **更新音乐库** 扫描所有已授权目录，文件大小与修改时间一致时复用已索引的标签。分类页可快速定位专辑、艺人、专辑艺人、流派和年份。歌曲可按标题、艺人、专辑、年份或导入顺序排序，专辑内按碟号和曲号排列。也可在 **设置 → 管理扫描目录** 单独重新扫描或移除授权。

### 歌词和歌单

- 同目录下的同名 `.lrc` 会在扫描时与音频关联。例如 `song.flac` 与 `song.lrc`。打开播放页的 **歌词** 可跟随进度滚动，点击歌词可定位时间。支持多时间戳和 `[offset:...]`、UTF-8、带 BOM 的 UTF-16 及 GB18030。
- **智能歌词补全**：在音乐库点击 **补全歌词** 或在单曲菜单选择 **下载歌词**，应用会跨 TIDAL 与网易云按歌名、艺人（支持繁简转换）及歌曲时长智能比对，挑选预览后直接将同名 `.lrc` 保存至本地音乐同级目录（SAF 授权目录）。
- 在 **音乐库 → 歌单 → 导入 M3U** 选择 `.m3u` 或 `.m3u8`，可按歌单相对路径或文件绝对路径匹配已录入的音频。未匹配的项会跳过。打开本地歌单后可 **导出 M3U**，输出 UTF-8 的 `.m3u8`，保留列表顺序和重复曲目。

播放器支持后台音频、系统媒体控件、进度跳转、随机播放、单曲与队列循环。队列和进度可以恢复。TIDAL 曲目提供时间戳时，歌词会跟随进度滚动。

## 安装和构建

需要 JDK 17、Android SDK Platform 36 和 Build Tools 35.0.0。配置 `ANDROID_HOME` 后，在本目录执行：

```sh
./gradlew :app:assembleRelease :app:lintRelease
```

Release APK 支持 Android 6.0（API 23）及以上。安装和覆盖升级需要签名 APK。带 API 36 的模拟器或设备可以运行后台媒体回归检查：

```sh
./gradlew :app:assembleDebugAndroidTest
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.tidalgui.player.test/com.tidalgui.player.PlaybackSmoke
```

## 在 Android 登录

打开 **音源 → 登录 TIDAL**。应用先申请设备授权，收到直达链接后会自动打开 TIDAL 网页。完成授权后返回听音室，应用会领取并保存会话。也可以用另一台设备访问授权网址并输入显示的设备码。

默认由后台申请设备码，需要后台预先配置获准的 TIDAL 设备客户端。**音源 → 账号设置** 仍提供浏览器 OAuth、手动配置设备客户端和导入已有会话。账号密码只在 TIDAL 网页输入。

普通 TIDAL 账号与设备客户端凭据是两种不同的配置。公开开发者 API 的凭据可能没有此播放器依赖的完整曲目接口权限。安装包未预填第三方设备客户端凭据。

## 切换音源首页

首页顶部可在 **本地音乐 / TIDAL / 网易云** 之间切换，也可从 **音源** 进入对应首页。在线首页以最近聆听和歌单为主。网易云登录后请求每日推荐和专属歌单，访客可浏览推荐歌单。网易云的「我的歌单」分为我创建的和我收藏的，「歌单广场」可按分类分页浏览。TIDAL 登录后展示收藏歌曲和歌单。底栏搜索默认跟随首页音源，搜索框仍可临时切换范围，各来源保留本次打开应用期间各自的关键词和分类。

## 在 Android 使用网易云音乐

选择 **搜索 → 网易云** 即可使用播放器默认后台（由服务器管理员启用）。自建服务可从 **音源 → 网易云音乐 → 接口设置** 填写 HTTPS 兼容 API 地址，清空即可恢复默认。歌曲、专辑、歌单和艺人沿用 TIDAL 的浏览方式，网易云歌曲可与 TIDAL、本地曲目混合排队。播放器沿用原有的音质切换、歌词和后台控制。

曲目菜单可分享歌曲或下载完整音频。Android 10 及以上保存到系统的 `Download/网易云`，旧版 Android 保存在应用专属下载目录。可播放及下载的曲目取决于接口服务的会话与曲目权限。在 **音源 → 网易云音乐 → 登录网易云** 生成二维码，用另一台设备上的网易云音乐 App 扫码并确认。账号会话用于播放和单曲下载。支持退出登录，账号收藏同步暂未接入。扫码登录使用播放器默认后台。

在网易云曲目菜单选择 **查看评论**，或在播放器点击 **评论**，可查看歌曲评论总数、红心总数、热门和最新评论，以及每条评论的获赞数。

兼容接口需要提供 `/cloudsearch`、`/album`、`/artists`、`/artist/album`、`/playlist/track/all`、`/song/url/v1`、`/lyric`、`/comment/music` 和 `/song/red/count`。个性页和歌单广场还使用 `/recommend/songs`、`/recommend/resource`、`/personalized`、`/top/playlist`、`/user/account` 和 `/user/playlist`。接口参数参考 [SPlayer-Next](https://github.com/SPlayer-Dev/SPlayer-Next)。

## 导入已有会话

1. 在已登录的桌面环境准备有效的 tiddl `auth.json`。桌面版从 `TIDDL_PATH` 指定的目录读取该文件。
2. 将文件传到 Android 设备。打开 **音源 → 账号设置 → 导入已有会话**。
3. 导入完成后，可从设备的共享目录删除含凭据的文件。应用仅在私有空间保存播放所需的访问令牌和账号信息。

播放使用 Media3，支持 TIDAL 返回的未加密直链和静态 MPEG-DASH。设置可选择低、高、无损及 Hi-Res。实际返回的音质显示在正在播放页。Hi-Res 可用性取决于账号会话、曲目和设备，音频参数显示的是流元数据。

如需沿用桌面端的 Hi-Res 会话，用已安装 tiddl 的 Python 在仓库根目录导出，再将导出的 JSON 导入 Android：

```sh
umask 077
python scripts/playback_token.py --android > android-session.json
```

生成的文件含访问令牌。导入后可删除临时文件。仅导入访问令牌的会话过期后，可以在手机重新授权或导入新文件。离线下载和官方个性化推荐页当前未接入。

## 局域网遥控

1. 手机和电脑连接到同一可信局域网。
2. 在 Android 的 **设置 → 设备与连接 → 局域网遥控** 启用功能，在电脑浏览器打开手机显示的网址，输入六位配对码。也可复制遥控链接打开，码会预填。配对码 10 分钟内可用一次。
3. 网页可以搜索并添加曲目、播放或暂停、切歌、拖动进度、调整循环和随机播放，以及重排或移除队列项。正在播放区显示封面、实际音质（Hi-Res 以金色标出）和进度；右侧「播放队列 / 搜索」切换，双击队列项播放，双击搜索结果设为下一首。
4. 键盘：空格播放/暂停，← → 快退/快进 10 秒，Shift + ← → 切歌，/ 打开搜索。完整模式下专辑、艺人、歌单和本地分类以封面网格显示。

手机发起 TIDAL 授权后，遥控网页会显示同一授权链接和授权码。手机已经配置有效的 TIDAL 客户端凭据时，网页也可以发起授权。账号密码仍在 TIDAL 网页输入，Android 应用负责等待授权结果。

遥控默认关闭，默认只接收当前 Wi-Fi 或以太网 IPv4 子网的连接。跨私有网段访问时，可开启 **允许其他私有网段**，网络本身须已允许互访。每次开启遥控都会生成新的链接。关闭遥控、网络断开或播放服务退出后，旧链接失效。遥控使用明文 HTTP，请在可信局域网使用。

## 多端后台和 Android 更新

打开 **设置 → 设备与连接 → 多端后台 → 配置后台**，填入 HTTPS 地址、设备标识及配对密钥。后台管理网页可以在 Android 和 Linux 播放器之间切换。每端单独登录 TIDAL。

在 **设置 → 应用更新 → 检查更新** 查看版本。发现新版后，选择 **立即升级** 或 **稍后**。应用校验下载的 APK 后打开系统安装界面。检查和下载更新使用构建时配置的中继地址，无需配对。详情见 [后台说明](../backend/README.md)。

## 局域网文件管理

先授权一个音乐目录。在 **设置 → 设备与连接** 开启局域网遥控并允许已配对浏览器管理音乐文件。网页可查看、上传、下载、重命名和永久删除已授权目录中的音频。删除前网页会确认，关闭遥控会关闭文件管理。上传目标为首个已授权目录，单个文件的传输上限为 200 MB。文件管理通过局域网直连。
